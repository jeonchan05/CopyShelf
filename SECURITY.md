# Security

CopyShelf is a community beta. Fixes are made in the current source; there is no long-term support policy yet.

Clipboard history is sensitive and stored locally without encryption. Use synthetic text and images in reports. Do not upload history files, passwords, API keys, or private screenshots.

If **Security → Report a vulnerability** is available, use GitHub's private vulnerability reporting. Otherwise, keep details of an unpatched vulnerability out of public issues and request a private reporting channel from the repository owner.

Downloads use an ad-hoc integrity signature and have no Apple notarization. Permissions remain controlled by macOS, and updates may need new grants. The app does not include an automatic updater or network service.
