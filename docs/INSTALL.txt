CopyShelf — unsigned community beta

Install
Open the DMG and drag CopyShelf.app to Applications. Open that copy.
This app is not Apple notarized. If macOS cannot verify the developer,
review the download origin and source. If you choose to run it, use the
per-app Open Anyway option in System Settings > Privacy & Security after
trying to open the app. See https://support.apple.com/en-us/102445.

Allow CopyShelf in Accessibility (Device Control and Data Access on newer
macOS) for automatic paste. Allow clipboard reads for background recording.
Screen Recording permission is not required for clipboard screenshots.

Use
The default shortcut is Option-Command-V. Search, select with arrow keys,
and press Enter to paste. Change the shortcut in Settings by clicking it
and pressing a combination with Command or Control. Escape cancels.
Settings also has pause, launch at login, and clear history.

Update
Quit CopyShelf from its menu and replace the app in Applications.
History and settings stay in your Library. Unsigned updates can require
re-allowing permissions. There is no automatic updater.

Privacy
History is stored locally as unencrypted JSON. Pause before copying private
content. Clear history removes the saved file, not backups or old disk blocks.

설치
Apple 공증을 받지 않은 공개 베타입니다. DMG를 열고 앱을 응용 프로그램
폴더로 옮긴 뒤 실행합니다. 개발자 확인으로 실행이 막히면 출처와 소스를
확인하고, 실행하기로 판단한 경우 시스템 설정 > 개인정보 보호 및 보안의
'그래도 열기'에서 해당 앱을 허용합니다.
자동 붙여넣기는 손쉬운 사용(최신 macOS의 기기 제어 및 데이터 접근),
백그라운드 기록은 클립보드 읽기 권한이 필요합니다. 화면 기록 권한은
필요하지 않습니다.
기본 ⌥⌘V로 열고 방향키로 선택, Enter로 붙여넣습니다. 설정에서 단축키를
클릭하고 ⌘ 또는 ⌃를 포함한 조합을 누르면 변경하며 Esc로 취소합니다.
업데이트는 앱을 종료하고 같은 위치에 교체합니다. 기록과 설정은 유지하며,
미서명 앱이므로 권한을 다시 허용할 수 있습니다. 기록은 암호화하지 않습니다.
